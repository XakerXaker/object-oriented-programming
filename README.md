# Объектно-ориентированное программирование (C#)

Репозиторий содержит реализации четырёх лабораторных работ, последовательно раскрывающих ключевые концепции объектно-ориентированного проектирования на языке **C#**: от базовых принципов инкапсуляции и полиморфизма до паттернов проектирования и архитектуры приложений.

Каждая работа покрыта модульными/функциональными тестами.

---

## Лабораторные работы

### ЛР 1 — Симулятор транспортного маршрута поездов

📄 [Условие лабораторной работы](labs/lab-1.md) · 📁 [Исходный код](src/Lab1) · 🧪 [Тесты](tests/Lab1.Tests)

Моделирование автоматизированной транспортной системы на магнитной подушке. Поезда проходят маршрут, состоящий из различных участков (обычные пути, силовые пути, станции), каждый из которых влияет на движение. Симулятор рассчитывает время прохождения и определяет успешность завершения маршрута на основе упрощённой физической модели.

---

### ЛР 2 — Конструктор образовательных программ

📄 [Условие лабораторной работы](labs/lab-2.md) · 📁 [Исходный код](src/Lab2) · 🧪 [Тесты](tests/Lab2.Tests)

Проектирование предметной области системы формирования и редактирования образовательных программ университета. Сущности (лабораторные, лекции, предметы, программы) могут создаваться на основе уже существующих с использованием порождающих паттернов. Реализована система авторства и разграничения прав на редактирование, а также валидация бизнес-правил (например, сумма баллов предмета = 100).

---

### ЛР 3 — Корпоративная система распределения сообщений

📄 [Условие лабораторной работы](labs/lab-3.md) · 📁 [Исходный код](src/Lab3) · 🧪 [Тесты](tests/Lab3.Tests)

Реализация гибкой системы маршрутизации корпоративных сообщений с несколькими типами конечных точек (пользователь, мессенджер, дисплей). Поддерживается группировка адресатов, фильтрация сообщений по уровню важности, логгирование. Интеграции (мессенджер, дисплей) изолированы от основной логики. Тесты используют моки для проверки поведения.

---

### ЛР 4 — Файловый менеджер

📄 [Условие лабораторной работы](labs/lab-4.md) · 📁 [Исходный код](src/Lab4) · 🧪 [Тесты](tests/Lab4.Tests)

Консольное приложение для взаимодействия с файловой системой: навигация, просмотр, копирование, перемещение, удаление, переименование файлов. Архитектура отделяет логику работы с ФС от консольного интерфейса и парсинга команд, что позволяет расширять систему новыми файловыми системами и режимами вывода. Дерево каталогов выводится с параметризуемой глубиной и настраиваемыми символами.

---

## Стек технологий

- **Язык и платформа:** C# 12, .NET 8
- **Тестирование:** xUnit, Moq (моки в ЛР 3), coverlet для покрытия
- **Статический анализ:** StyleCop.Analyzers, SourceKit.Analyzers, `.editorconfig`; предупреждения компилятора трактуются как ошибки
- **Сборка:** MSBuild, централизованное управление версиями пакетов (`Directory.Packages.props`)
- **CI:** GitHub Actions (сборка и прогон тестов)
- **Подходы:** SOLID, GRASP, паттерны GoF (Builder, Prototype, Composite, Visitor, Chain of Responsibility, Facade, Command и др.)
